# Demo 的完整衣櫃

## 衣櫃概況

- 總件數：200
- 這份範例以可長期持有、可重複搭配的日常衣物為主，另外保留正式、換季、工作與興趣活動用品。
- 每一列代表一個可獨立辨識的款式／色款；同一剪裁只要顏色不同，就必須分列，不能用「黑／白」合併成一列。
- 數量是實際持有件數，不是建議購買量。狀態描述目前是否在穿、是否收納或是否作為備品；備註補充版型、保養、替換與收納位置。

## 推導與備註

- 以每週固定洗衣、日常通勤、週末活動與換季收納推導替換量；內衣、內褲與襪類按洗衣週期保留足夠輪替。
- 同一剪裁只在「顏色、材質、版型、用途與狀態都相同」時才可合併；不同顏色即使剪裁相同，也必須拆成不同款式列出。
- 備註具體記錄穿著頻率、替換位置、保養方式、收納方式或可搭配對象，不以「可搭配多種衣物」等空泛句子帶過。
- 正式場合與季節性需求用少量重點單品補足；數量反映角色實際持有，不把建議購買清單混入衣櫃總件數。
