## BUG2-01：發布 PNG 被下一次 read 自動封存

根因：
- archiveExistingLegacyLayout（core 1566-1577）與 migrateLegacyLayoutIfNeeded（core 1522-1527）的 keep 集合只認 `latest.png_base64 !== undefined`；使用 png_ref 的目前發布不 keep → PNG 被搬進 .workspace/legacy-layout/migration-*。
- materializedFiles（core 2023-2037）只從 inline content/png_base64 重建，不從 content_ref/png_ref blob 還原。

修法：
1. 兩處 keep 條件改為 `latest.png_base64 !== undefined || latest.png_ref !== undefined`（有 PNG 資料即保留 export_png_path 對應檔）。
2. materializedFiles 改 async（private，僅 reconcileMaterializedFiles 1600 與 writeTransactional 1624 呼叫，皆 async）：content_ref/png_ref 存在時從 this.blobs.get(hash) 還原（blob 遺失則略過該檔）。
3. 新增整合測試：publish（png_ref）→ repository.read() 重開 → exports PNG 檔仍存在、legacy-layout 不含該 PNG。

## BUG2-02：Required Manifest 選到最舊 Character revision

根因：required-artifacts.ts latestCharacterFor（151-167）用 `score > bestScore`——同分（同一角色的後續 revision 得分相同）保留最先出現的舊 revision；manifest in_scope_artifact_ids 綁舊 id；gate 以 id 交集過濾 review scope → 新版 character 逃過 review，compiler 卻打包新版。

修法：
1. latestCharacterFor 改為 `bestScore === 0 ? score > 0 : score >= bestScore`（同分取最後出現＝最新 revision；score 0 仍不選）。
2. 新增測試：同 key 兩 revision character → manifest 選最新 id；gate publish 對舊 review + 新 revision 會要求新 revision review。

## BUG2-03：gate 與 compiler 使用不同 artifact 集合

根因：
- manifest review scope 不含 plugin、不含 roster 外符合全域模式的 zhuji/palette、world/relationships 只在 enabled 時納入。
- compiler isIncludedArtifact 只排除技術 kind：world/relationships 停用仍打包、plugin 永遠打包、roster 外 mode artifact 依全域模式打包。
- reportBlueprintBindings 檢查所有 latest artifact 而非 manifest scope → 不打包卻阻擋。

修法：單一 BuildPlan（放 core，compiler 與 domain 共用，避免依賴循環）。
1. core 新增：
   ```ts
   export interface BuildPlanEntry { key: string; artifact_id: string; kind: ArtifactKind; revision: string; }
   export interface BuildPlan {
     mode_selection?: "zhuji" | "palette" | "both";
     world_enabled: boolean;
     relationships_enabled: boolean;
     entries: BuildPlanEntry[];
   }
   export function computeBuildPlan(state: ProjectState, modeSelection?: CardModeSelection): BuildPlan
   ```
   - latest-by-key 投影；排除 NON_CARD kinds 與 blueprint。
   - zhuji/palette（parse content.mode）：依 modeSelection 篩（undefined 全含）。
   - world_lore：blueprint.world enabled 才含；relationship：blueprint.relationships enabled 才含。
   - character/wardrobe/greeting/plugin：含。
2. compiler normalizeProject：isIncludedArtifact 替換為 plan.entries id 集合（modeProjection 語意保留在 plan）。
3. workflow-gate：
   - reportReviews/reportBlockingIssues scope = manifest in_scope ∪ plan.entries。
   - reportBlueprintBindings 只檢查 plan.entries 內 key 的 latest artifact。
4. 新增測試：world disabled + 舊 world artifact → gate 不要求 review、compiler 不打包；plugin 進 review scope；roster 外 zhuji 在全域模式命中時進 scope；未選模式 artifact 不被 BLUEPRINT_BINDING_STALE 阻擋。
