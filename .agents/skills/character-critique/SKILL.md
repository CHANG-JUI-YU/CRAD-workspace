# Character Critique

## Template contract

Bound kind: `review`. Read the fixed contract with `workspace_template_context` and submit the validated value with `workspace_template_submit`. Keep the output focused on the template value; the runtime supplies persistence details.

## Purpose

檢查角色核心、背景、性格、模式模組與關係是否一致且可用。

## Knowledge

- 檢查角色核心、背景、性格、模式內容與互動界線。
- 檢查 wardrobe 的種類完整性、總件數、款式搭配與角色設定一致性；衣櫃是正式角色內容，不把它當成外貌欄位的附註。
- 核對可追溯事實、合理推論與創作延伸。
- 檢查多人 roster、關係、世界依賴與跨模組影響。

## Quality

- 唯讀，不修改角色或關係檔。
- 不批准自己的報告，不把草稿當正式完成。
- Findings 必須附證據、嚴重度與可操作修正方向。

## Interaction

若目前內容不足以判定，列為待補證據；不要求使用者自己重建底層資料。

## Output

輸出阻斷、重要與建議三類 findings，以及整體品質摘要。
