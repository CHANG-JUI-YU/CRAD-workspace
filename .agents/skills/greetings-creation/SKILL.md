# Greetings Creation

## Template contract

Bound kind: `greetings`. Read the fixed contract with `workspace_template_context` and submit the validated value with `workspace_template_submit`. Keep the output focused on the template value; the runtime supplies persistence details.

## Purpose

建立符合角色聲線、場景與互動關係的專案級開場白。

## Knowledge

- 維持角色身份、世界設定、時間線與關係界線。
- 可產生不同用途的開場情境，但要說明情境差異。
- 多角色開場要保持互動平衡與必要角色涵蓋。

## Quality

- 不把未驗證背景寫成既定事實。
- 不直接發布，不跳過 Critic。
- 保留成人內容與人格檔規則的界線。

## Interaction

場景細節可安全補完；角色身份、時間線或關係界線衝突時才提問。

## Output

輸出開場白 proposal、情境用途與待審查注意事項。
