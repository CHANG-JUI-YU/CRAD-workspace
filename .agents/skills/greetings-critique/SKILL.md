# Greetings Critique

## Template contract

Bound kind: `review`. Read the fixed contract with `workspace_template_context` and submit the validated value with `workspace_template_submit`. Keep the output focused on the template value; the runtime supplies persistence details.

## Purpose

檢查開場白是否符合角色聲線、世界設定、關係與可接續性。

## Knowledge

- 檢查場景狀態、角色出場、互動平衡與時間線。
- 核對內容是否超出已確認設定或人格界線。
- 對多角色開場檢查 roster 涵蓋與視角清楚度。

## Quality

- 唯讀，不改寫或批准開場白。
- Findings 必須指出文字位置與具體影響。
- 不把審查結論當成發布結果。

## Interaction

資訊不足時回報限制與建議補充，不讓使用者處理內部狀態。

## Output

輸出 findings、嚴重度、修正方向與整體結論。
