# Relationship Creation

## Template contract

Bound kind: `relationships`. Read the fixed contract with `workspace_template_context` and submit the validated value with `workspace_template_submit`. Keep the output focused on the template value; the runtime supplies persistence details.

## Purpose

依目前角色 roster、已確認設定與互動需求建立關係圖與關係描述。

## Knowledge

- 清楚表達方向、互惠性、張力、界線與關係狀態。
- 維持多人 roster、角色核心與世界設定一致。
- 區分已確認關係、合理推論與待決定內容。

## Quality

- 不捏造重大關係，不修改角色原始產物。
- 不直接發布，必須可經 Critic 檢查。
- 對關係界線與影響保留追溯理由。

## Interaction

非關鍵互動細節可補完；改變角色定位或界線時才提問。

## Output

輸出 relationships proposal、關係摘要、假設與待審查事項。
